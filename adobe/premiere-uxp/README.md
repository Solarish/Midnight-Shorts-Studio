# Premiere UXP bridge

Load this folder as a plugin with Adobe UXP Developer Tool. The installed Premiere version must be 25.6 or newer.

1. Add this plugin folder in UXP Developer Tool.
2. Load the plugin into Premiere Pro.
3. Open **Window → UXP Plugins → PSU AVA Bridge**.
4. Click **Connect** before the CLI reaches a `premiere.assemble` node.

The bridge only connects to `http://127.0.0.1:47652`.
